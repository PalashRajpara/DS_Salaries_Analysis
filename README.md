# Data Science Salaries Analysis

Exploratory analysis of the DS Salaries dataset using a Jupyter notebook.

## Contents

- `ds_salaries.ipynb`: Primary analysis notebook with data loading, cleaning, and visuals.
- `ds_salaries.csv`: Source dataset used by the notebook.

## Getting started

1. Create and activate a Python virtual environment.
2. Install dependencies used in the notebook.
3. Open the notebook and run cells top to bottom.

Example setup (macOS/Linux):

```bash
python -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install pandas numpy matplotlib seaborn
```

## Notes

- If you add new packages in the notebook, update the install list above.
- For large outputs, consider clearing notebook output before committing.
